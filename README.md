Brand & Visual Direction:
- Main website: https://www.jokarcreations.com/
- Use Poppins font throughout.
- Dark, cinematic backgrounds: deep black (#0B0B0F / #050508), charcoal, white, with subtle electric purple and violet ambient lighting, depth, and restrained bloom (inspired by the reference screenshot attached).
- Use the attached JOKAR Creations logos (gradient, white, cyan, and black versions).
- Interactive filtering: Browse by Service (All Work, Branding & Graphic Design, Web Development, Digital Marketing) and browse/filter by Client (viewing all services delivered for that specific client).
- Editorial layout with interactive project modals/detail views, statistics showcase, client stories, and a strong contact/project inquiry section.
